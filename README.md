# christiankarlsson.xyz

Christiankarlsson.xyz är en samlingsplats för min närvaro på sociala medier. Följare och andra intresserade ska kunna besöka webbplatsen för att få en samlad bild av vilka plattformar jag finns på och vad jag skriver om.

## Mobil först

Webbplatsen utvecklas enligt principen Mobile First, med målet att ge besökarna bästa möjliga upplevelse på mobila enheter.

## Sociala medier

### Mastodon

Min Mastodon-instans finns på mastodon.christiankarlsson.xyz och kan även nås via christiankarlsson.xyz/mastodon.

Varje inlägg på webbplatsen länkar till det ursprungliga inlägget på Mastodon.

Christiankarlsson.xyz lagrar följande information om varje inlägg:

- Ämne
- Datum och tid
- Länk till originalinlägget
- Rubrik
- Innehåll

Inlägg ska kunna skrivas och publiceras på tre olika sätt:

1. Direkt på Mastodon.
2. Via christiankarlsson.xyz.
3. Som en Markdown-fil som sedan publiceras på Mastodon.

Christiankarlsson.xyz hämtar inläggen från Mastodon.

## Följ mig

På sidan `/follow` samlas och visas inläggen. Informationen som visas är inläggets rubrik och innehåll.

## Om mig

Sidan presenterar mig med namn och profilbild.

## Källkod

Källkoden från projektets `main`-branch publiceras på github.com/christiankarlssonxyz.
